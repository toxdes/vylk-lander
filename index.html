Nothing extra to manage.

Just the pieces that help you write, find, and return to your notes.

write

See the note as you write it

See your formatting as you write. Use the toolbar for headings and lists, then go fullscreen when you want to focus.

offline

Keep working without internet

The installed PWA caches its shell and notes, saves edits in IndexedDB, and syncs when your connection returns.

shape

Make the workspace yours

Choose your colors and fonts. Show the tools you use, hide the ones you don't, and give your words more room.

protect

Protect what is on disk

Turn on optional encryption to protect note contents stored on your server. Titles and tags are stored separately; the docs explain what's covered.

devices

Write in your desktop or mobile browser. Add VYLK to your home screen to open it like an app.

save

Save as you go

Your changes save as you pause. Prefer to save them yourself? That's always an option too.

Add the APT repository (one-time)
sudo apt update && sudo apt install -y ca-certificates curl gnupg && curl -fsSL https://packages.toxdes.com/apt/pubkey.gpg | sudo gpg --dearmor --yes -o /usr/share/keyrings/toxdes-archive-keyring.gpg && echo "deb [signed-by=/usr/share/keyrings/toxdes-archive-keyring.gpg] https://packages.toxdes.com/apt stable main" | sudo tee /etc/apt/sources.list.d/toxdes.list && sudo apt update

To install:

sudo apt install vylk

To start VYLK:

VYLK_PASSWORD='replace-with-your-password' vylk

Add the DNF repository (one-time)
printf '%s\n' '[toxdes]' 'name=Toxdes' 'baseurl=https://packages.toxdes.com/rpm' 'enabled=1' 'gpgcheck=1' 'repo_gpgcheck=1' 'gpgkey=https://packages.toxdes.com/rpm/pubkey.gpg' | sudo tee /etc/yum.repos.d/toxdes.repo

To install:

sudo dnf install vylk

To start VYLK:

VYLK_PASSWORD='replace-with-your-password' vylk

Use the published VYLK image. Notes and the database stay in a named volume.

To start VYLK:

docker run -d --name vylk -p 127.0.0.1:8080:8080 -e VYLK_PASSWORD='replace-with-your-password' -v vylk-data:/data toxdes/vylk:{version}

Open localhost:8080 after the container starts.

Requires Git and Go 1.25.1+.

To build:

git clone https://github.com/toxdes/vylk.git
cd vylk
go build -trimpath -ldflags="-s -w -X main.version=$(cat VERSION)" -o vylk .

To start VYLK:

VYLK_PASSWORD='replace-with-your-password' ./vylk

Build from source

Install Go, then build VYLK from the public source repository.

git clone https://github.com/toxdes/vylk.git && cd vylk
go build -trimpath -ldflags="-s -w -X main.version=$(cat VERSION)" -o vylk .
VYLK_PASSWORD='replace-with-your-password' ./vylk

Choose your own password. Keep VYLK running.
Open localhost:8080 and start writing.
